## AC-1: V-COH-001 formal apps present or reported
```gherkin
Given catalogue artifacts of formal application type (type starts with F_3G, not _SCRIPT/_AUX)
When layout.appDir(id) does not exist under root
Then one note per artifact "not started" listing its cases
And existing folders → pass
```

## AC-2: V-COH-002 every repo artifact cited
```gherkin
Given artifacts present in the tree: formal app folders, XML files, Annex B manifests (IDs via ids.fromFolderName)
Then each must exist in the catalogue with ≥1 case; otherwise should-fix
And filler folders are out of scope (no catalogue ID)
```

## AC-3: V-COH-003 README group-document version
```gherkin
Given a formal app folder README.md
When it states "G<NNN> group document v<X>" (or "group document ST3_F_G_<NNN> v<X>")
Then X must equal catalog.sources() version for that group; mismatch → should-fix
And a README that states no version for a group the app belongs to → note
And no README → skipped (README structure is readme.js's job)
```

## AC-4: V-COH-004 open escalations recorded as risk
```gherkin
Given the app's catalogue cases and their escalations
When an escalation is open (escalation_status.open === true)
Then its code must appear in the README (word-bounded, e.g. \bE23\b); missing → should-fix naming code and cases
And no open escalation for the app → pass
```

## AC-5: V-COH-005 evidence covers the case list
```gherkin
Given a formal app folder (built)
Then evidenceDir(id)/self-test.md exists (else should-fix)
And the case IDs in its "## Summary" table equal the artifact's catalogue cases (missing and extra both reported)
And no Summary table → should-fix
```

## AC-6: V-COH-006 retired IDs not reused
```gherkin
Given catalogue retired_declarations
Then no file under codeRoots, the xml directory or annexB (text files: .js .ts .html .css .json .xml .md .lua .ncl .py) mentions a retired ID (word-bounded)
And each hit → blocking with file and line
And docs/specs, docs/project and catalog-overrides are not scanned (they record the retirement)
And no retired IDs in catalogue → skipped
```

## AC-7: Targets, adapter, real run
```gherkin
Given an ID target → only that artifact's checks; path target → artifacts under it
And adapter unavailable → all six skipped with reason
And real AtlantisPB run explainable; recorded in SUMMARY, not committed
```
