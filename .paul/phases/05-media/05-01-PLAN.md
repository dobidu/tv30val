<objective>
## Goal
Add the `media` family to the catalogue (V-MED-001..004) and implement V-MED-001..003 over application media assets (`<app>/assets/{audios,fonts,hstreams,images,texts,videos}/`), dependency-free. V-MED-004 skips "plan 05-02".

## Purpose
Media assets are artifacts the handoff left out. Their folder/name form is already enforced by AtlantisPB's `check-structure.js`; this family checks content: the file is the media ID the catalogue knows, its bytes are what its extension says, and its kind belongs in the folder it sits in.

## Output
- 4 new catalogue entries (family `media`), FAMILIES gains `media`
- `lib/media.js`: magic-byte sniffer; `lib/normative/media-formats.js`: kind ↔ folder ↔ extensions
- `lib/families/media.js`; synthetic media fixtures (tiny generated files); tests; README
</objective>

## AC-3: V-MED-001 catalogued media IDs
```gherkin
Given a media item named <kebab>[.<ext>]
Then ids.fromFolderName(<kebab>) must be a catalogue artifact of a media type (HSTREAM, HVIDEO, MHAUDIO, HFILE, HREF, MMEDIA, AUDIO, TEXT) with ≥1 case
And for formal apps, at least one of its cases must also be a case of the app (the app actually uses it); otherwise should-fix
And fonts/ files are exempt (fonts are not catalogued media) → no result
And unparseable names → blocking "not a media ID"
And adapter unavailable → skipped
```

## AC-4: V-MED-002 content matches extension
```gherkin
Given a media file (not directory)
Then its magic bytes identify a format whose extension list contains the file's extension
  (png, jpg/jpeg, gif, webp, svg[xml text], bmp; mp4/m4s/m4a/mov[ftyp], webm/mkv[EBML], ogg/oga/ogv/opus, mp3[ID3|frame sync], wav[RIFF/WAVE], aac[ADTS], flac;
   ttf/otf/woff/woff2; mpd[XML with <MPD], m3u8[#EXTM3U], vtt[WEBVTT], ttml/xml[XML], txt/json/html as text)
And mismatch → blocking with detected vs declared
And unknown signature → note "format not recognised" (never pass)
And empty file → blocking
```

## AC-5: V-MED-003 kind matches folder
```gherkin
Given lib/normative/media-formats.js mapping folders → kinds (images: image; audios: audio; videos: video; hstreams: stream manifest/segments/subtitles; texts: text/subtitle; fonts: font)
When a detected format's kind is not allowed in its folder
Then should-fix "a <kind> file in <folder>/"
And a format recognised but not in any allowlist → note "format not in the recorded allowlist (to confirm against NBR 25608)"
```

## AC-6: Targets
```gherkin
Given an app ID / path target → only media under it; a media ID target → only that item
```
