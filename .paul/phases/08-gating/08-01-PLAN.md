<objective>
## Goal
Add an opt-in gate (`--gate <family,…>`): only blocking findings in the gated families set exit code 1, so the team can enforce trusted families in CI while the rest stays advisory. Update the team-facing docs for everything v0.2 added, verify on the real repo, release v0.2.0, and decide where Phase 9 (API index) lives.

## Purpose
Handoff §10.3 recommends advisory in v0.1 and gating on blocking from v0.2. A per-family gate lets that happen gradually instead of all at once.

## Output
- `--gate` option; report shows which findings gate; tests
- docs/decisions-draft.md v0.2 entry; docs/integration.md gate + CI snippet; README; version 0.2.0
- Phase 9 decision recorded
</objective>
