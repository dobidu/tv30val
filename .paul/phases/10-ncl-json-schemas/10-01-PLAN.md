<objective>
## Goal
Add V-APP-012: every Ginga-NCL application's `main.ncl` validates against `NCL4.0/profiles/NCL40.xsd` from the committed complementary files, with the profile's `http://www.ncl.org.br/NCL4.0/…` imports mapped to the local `NCL4.0/` folder (xmlschema `uri_mapper`; xmllint XML catalog).

## Purpose
Completes XML-side schema coverage (the team backlog asks for one schema-validation command). NCL apps are coming (NCL scaffold exists); validating them from day one avoids the PRRD situation.

## Output
- Catalogue entry V-APP-012 (44 checks); NCL validation in `lib/xml.js`; check in app family
- Decisions draft note: JSON schemas deferred + the `minmum` typo in the official nga schemas
</objective>

<context>
@lib/xml.js (validateXsd, xmlschema script), lib/families/app.js, lib/context.js (schemas, validator)

## Facts (AtlantisPB docs/project/normative-schemas.md + complementary files)
- `NCL4.0/profiles/NCL40.xsd`; root `ncl`, namespace `http://www.ncl.org.br/NCL4.0/NCL4Profile`; 26 imports with `schemaLocation="http://www.ncl.org.br/NCL4.0/modules/…"` (no longer resolves) plus some relative ones.
- Team recipe: xmlschema `XMLSchema(NCL40.xsd, uri_mapper=lambda uri: local path if uri.startswith("http://www.ncl.org.br/NCL4.0/") else uri)`.
- Known difference: AtlantisPB's NCL scaffold still writes the NCL 3.0 EDTV profile namespace as a placeholder.
- No NCL apps in AtlantisPB today.
- JSON: AMM/nga/user schemas use oneOf, format, maximum, maxLength, maxItems, multipleOf, patternProperties, unevaluatedProperties and cross-file `$ref` (incl. `urn:nga:…` ids); no saved reports exist in the repo. nga `preset`/`switchgroup` (get and post) misspell `minimum` as `minmum`.
</context>
